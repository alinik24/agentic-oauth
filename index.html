agentic

agentic is a personal automation assistant ("Hermes") operated by its owner. It connects the owner's own Google accounts to a single local agent so that the owner can search and read their own email, calendar, contacts and files across accounts, and (when explicitly enabled) draft or send email on the owner's behalf.

What this application does

  • Uses Google OAuth 2.0 (public "installed app" flow, PKCE, loopback redirect) to authenticate the owner's own accounts.
  • Reads the owner's Gmail, Calendar, Drive, Docs, Sheets and Contacts data to provide a single unified search and read interface.
  • Only the owner's explicitly connected accounts are accessed; the application never accesses other users' data.
  • Write operations (sending mail) are disabled by default and only enabled after explicit per-account approval.

Google services accessed

  • Gmail (read, search; send only where explicitly enabled)
  • Google Calendar
  • Google Drive (files and metadata)
  • Google Docs
  • Google Sheets
  • Google Contacts
