Privacy Policy

Effective date: 2026-10-11

1. Who operates this application

agentic is a personal automation assistant ("Hermes") operated by a single individual (Ali NiK, the "owner") on the owner's own computer. It is not a commercial product and is not offered to the public.

2. Data accessed

The application connects only to Google accounts that the owner has explicitly authorized through the Google OAuth consent screen. With the owner's consent it may access:

  • Gmail messages and metadata
  • Google Calendar events and settings
  • Google Drive files and metadata
  • Google Docs documents
  • Google Sheets spreadsheets
  • Google Contacts

The application does not access data of any user other than the owner of the connected accounts.

3. How data is used

Data is used solely to provide the owner with a unified search/read interface across the owner's own accounts, and — only where the owner has explicitly enabled sending for a given account — to compose and send email on the owner's behalf. Data is never sold, rented, or shared with third parties for advertising or any other purpose.

4. Where data is stored

OAuth credentials and tokens are stored locally on the owner's computer under the owner's local Hermes data directory. No account data, message content, tokens or credentials are written to this website or transmitted to any third-party server by the application.

5. Data sharing

The application does not share any user data with third parties. Outbound network traffic is limited to Google's own API endpoints (accounts.google.com, www.googleapis.com, oauth2.googleapis.com) when the owner uses the application, and to Microsoft/KIT Exchange endpoints only for the owner's KIT mailbox integration if enabled.

6. Data retention

OAuth tokens are retained in the local account directory until the owner revokes access (via Google's account settings or by deleting the token files). The application does not operate a server and does not retain data on any cloud infrastructure.

7. Data deletion

To delete all data, the owner deletes the local account token files (accounts/google/*/google_token.json) and revokes access at myaccount.google.com/permissions. No server-side copy exists to delete.

8. Security

Tokens are stored only on the owner's local machine. The application uses standard OAuth 2.0 with PKCE. The owner is responsible for protecting the local machine and the passwords used to unlock it.

9. Changes to this policy

This policy may be updated as the application evolves. The effective date above indicates the latest revision.

10. Contact

This is a personal application; the owner can be reached directly at alinazarikhah1@gmail.com.
